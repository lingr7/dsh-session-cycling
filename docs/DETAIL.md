# 会话循环切换

给主视图增加四个命令，用来在并行会话之间移动。命令出现在「设置 → 通用设置 → 编辑快捷键」里，键位可以随时改，也可以被遥控器（SayAll 的 `shortcut` 动作）直接触发。

## 默认键位（Desktop Windows / macOS）

| 命令 | 默认键 | 行为 |
| --- | --- | --- |
| 切换到上一个会话 | `Alt+↑` | 按侧栏列表顺序回到上一个会话，到顶后绕回末尾 |
| 切换到下一个会话 | `Alt+↓` | 按侧栏列表顺序前进到下一个会话，末尾后绕回开头 |
| 切换到上次使用的会话 | `Alt+←` | 在最近两个会话之间来回切，适合同一时间只盯两件事 |
| 切换到下一个运行中的会话 | `Alt+→` | 跳到下一个 Agent 仍在运行（`running`）的会话，用于巡视并行任务 |

Web 端与 Linux 桌面端不设默认键位：DSH 的快捷键协议把裸方向键判为保留键（`bindingIssue` 返回 `reserved`），随手写进默认值会让注册直接抛错，插件静默失效。需要的话在「编辑快捷键」里自己指定组合。

## 实现要点

- 只切主视图：调用 `uiWorkspace.openSession`，不新建、不归档、不重命名、不停止任何会话。
- 跳过子代理会话与还没发过消息的空草稿（`origin === 'subagent'`、`blank === true`），避免落到没有内容的行。
- 可用会话少于两个时返回 `status: 'pass'`，按键继续交给输入框。
- 原生快捷键桥之外还有一层 DOM 兜底：窗口捕获阶段监听 `Alt+方向键`，只有原生路径没拦截时才生效，因此不会重复执行。兜底同时接受 `event.code` 与 `event.key`，以兼容不带扫描码的合成按键。

## 遥控器映射（已写入 SayAll）

`%APPDATA%\app.getsayall.remote-mic.windows\button-mappings.json`：

- 双击 ← → `alt+up`（上一个会话）
- 双击 → → `alt+down`（下一个会话）

单击仍是光标左/右移，长按仍是 Home/End。改完必须重启 `sayall-windows-app.exe` 才会重新读取配置。

## 范围与限制

- 只在主视图里切换会话；右侧栏、面板、设置页不受影响。
- 不处理「关闭会话」「归档后回到哪个会话」这类语义，交给 DSH 自己的命令。
- 系统级组合键（例如显卡驱动的 `Ctrl+Alt+方向键`）刻意没有占用。
